
## Descripción de las Secciones

### Header
- **Logo SVG**
- **Navegación**: Menú de navegación que se convierte en un menú de hamburguesa en dispositivos móviles.

### Hero
- **Imagen**
- **Información**: Tu nombre, apellidos y una breve descripción como desarrollador full-stack.
- **Iconos**: Iconos de tu stack tecnológico (HTML, JS, CSS, PHP).
- **Botón**: Botón para descargar tu CV.

### Titulaciones
- **Carrusel**: Carrusel de imágenes con 4 diplomas que cambian cada 3 segundos.
- **Modal**: Botón para ver todas las titulaciones en un modal.

### Proyectos
- **Cards**: Dos cards de proyectos diferentes.
- **Modal**: Botón para ver todos los proyectos en una página separada.
- **Detalles**: Cada card tiene un botón para ver más detalles en un modal.

### Contacto
- **Formulario**: Formulario de contacto que envía correos a `lodostrinidad@gmail.com`.

### Footer
- **Diseño**: Un footer bien trabajado y estilizado.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- [EmailJS](https://www.emailjs.com/) (para el formulario de contacto)
